# Gestion_Restaurantes_La33
- Un sistema de restaurantes con arquitectura de microservicios

## Microservicios
- Autenticacion y Usuarios
- Gestion de restaurantes
- Menu e Inventario
- Mesas y Reservaciones
- Mesas y Entregas 
- Eventos y Promociones
- Reseñas y Notificaciones
- Analisis y Reportes

## Base de datos
- PostgreSQL
- MongoDB

## Estructura del proyecto
- Se inicia el proyecto
- Entrega el 35% de el proyecto de restaurantes.
